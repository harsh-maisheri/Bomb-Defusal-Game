# Bomb Defusal Game

An academic desktop game project built with Python and Pygame. The player works through a timed bomb-defusal puzzle with interactive screens and visual clues.

## Features

- Interactive Pygame interface
- Timed gameplay
- Multiple puzzle and instruction screens
- Custom visual assets

## Technology

- Python 3
- Pygame

## Run locally

1. Install Python 3.
2. From the repository root, install the dependency:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start the game:

   ```bash
   python bomb_defusal_game.py
   ```

Run it from the repository root so the game can find its image and sound assets.

## Project structure

- `bomb_defusal_game.py` — main game
- `requirements.txt` — Python dependency
- Asset files in the repository root — images and other media used by the game

The repository also contains smaller Python practice programs from the same learning period; the main game entry point is listed above.
